# Especificación Técnica: iToken - Banco Itaú Uruguay

Este archivo ha sido diseñado para proporcionar una documentación estructurada y detallada sobre la funcionalidad **iToken**, optimizada para su procesamiento por modelos de inteligencia artificial y especialistas en ciberseguridad bancaria.

## 1. Definición del Producto
**iToken** es una clave digital de seguridad avanzada diseñada para validar transferencias digitales realizadas a través de los canales electrónicos de Banco Itaú Uruguay. Actúa como el principal método de autenticación para operaciones que superan ciertos umbrales de seguridad.

## 2. Atributos y Beneficios Clave
*   **Seguridad Reforzada:** Ofrece una protección superior para las transferencias de fondos.
*   **Agilidad Operativa:** Las transferencias realizadas desde la aplicación móvil se validan de forma automática.
*   **Simplificación:** Elimina la dependencia de otros métodos de validación tradicionales como mensajes de texto (SMS) o correos electrónicos.
*   **Disponibilidad:** Permite la validación de operaciones desde cualquier ubicación geográfica a través de dispositivos móviles.

## 3. Umbrales de Operación
El uso de iToken es obligatorio y sustituye a otros métodos de validación para todas las transferencias que cumplan con las siguientes condiciones:
*   **Monto:** Operaciones a partir de **USD 50** o su equivalente en pesos uruguayos.
*   **Tipos de transferencia:** Es aplicable para transferencias entre cuentas Itaú, hacia otros bancos locales y para giros internacionales.
*   **Token Físico:** En los casos donde la transferencia requiera específicamente un token físico, este último seguirá siendo el método de validación vigente.

## 4. Proceso de Adhesión (Habilitación)
La adhesión a iToken se realiza exclusivamente a través de la **App Itaú** siguiendo este protocolo:
1.  Ingresar a la aplicación móvil oficial de Itaú.
2.  Seleccionar el ícono de **iToken** ubicado en la parte inferior de la pantalla.
3.  Autenticarse con el documento de identidad y contraseña, o mediante biometría (huella dactilar).
4.  Aceptar los términos y condiciones del servicio.

## 5. Dinámica de Uso según el Canal
*   **Desde la App Itaú:** El sistema iToken funciona de manera automática; no se requiere ninguna acción adicional por parte del usuario para validar la transferencia.
*   **Desde la Web (Itaú Link):** Al realizar una transferencia, el usuario debe seleccionar "iToken" como método de validación. Posteriormente, debe abrir la app en su celular, presionar el botón iToken y copiar el código numérico generado en el sitio web.

## 6. Políticas de Seguridad y Gestión de Dispositivos
*   **Exclusividad:** Por motivos de seguridad, el iToken solo puede estar habilitado en **un dispositivo celular por número de cédula**.
*   **Baja del Servicio:** Para desactivar el iToken, el cliente debe ingresar a la web oficial con su usuario y clave, navegar al menú de perfil, seleccionar **"Gestión de Tokens"** y confirmar la baja en la opción "iToken".
*   **Cambio de Dispositivo:** Antes de cambiar de teléfono móvil, es estrictamente necesario dar de baja el iToken en el dispositivo anterior a través de la web. Una vez completada la baja, se podrá realizar el proceso de adhesión en el nuevo terminal.
